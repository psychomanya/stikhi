# СтихоУм — Изучение стихотворений наизусть

Интерактивное веб-приложение для эффективного заучивания стихотворений наизусть с пошаговым сокрытием слов, персональной библиотекой и мастером форматирования.

---

## 📖 Как работает методика заучивания

Логика заучивания воспроизводит и расширяет алгоритм оригинального телеграм-бота:

1. **Пошаговое скрытие слов (`▒▒▒▒`):**
   - **Уровень 1 (10%):** Скрываются первые несколько слов в каждой строке для легкой разминки.
   - **Уровень 2 (43%):** Скрывается почти половина слов — тренировка активного припоминания.
   - **Уровень 3 (76%):** Скрыта большая часть текста — глубокое закрепление памяти.
   - **Уровень 4 (100%):** Скрыты все ключевые слова — полная проверка знания наизусть!
2. **Правила сокрытия:**
   - **Короткие слова (≤ 2 букв)** — предлоги и союзы (*«и»*, *«в»*, *«на»*, *«не»*, *«он»*, *«за»*) **никогда не скрываются**, сохраняя размер, паузы и ритмику стиха.
   - **Знаки препинания** (запятые, тире, кавычки, восклицательные знаки) остаются на своих местах.
   - **Длина слова сохраняется** — каждая буква маскируется символом `▒`, подсказывая слоговую структуру.
3. **Управление сложностью (как в кнопках бота):**
   - **«Сложнее ➡️»** — увеличивает скрытие на 33% на каждом шаге.
   - **«⬅️ Легче»** — уменьшает скрытие на 33%, если стало трудно.
   - **«🫣» / «🙈»** — моментально подглядеть весь стих и спрятать слова обратно.
   - **Клик по конкретному слову:** Нажмите прямо на любое замаскированное слово `▒▒▒▒`, чтобы точечно подсмотреть только его, не открывая весь стих!
4. **Режимы сокрытия:**
   - **Накопительный (по умолчанию):** слова, скрытые на шаге 1, гарантированно остаются скрытыми на шаге 2. Идеально для последовательного заучивания.
   - **Случайный:** классическая логика бота, выбирающая случайные слова по проценту.
   - **Тренировка рифм:** скрываются только последние слова строк.
   - **Тренировка начал:** скрываются первые слова каждой строки.

## 🪄 Добавление своих стихов и «Приведение в порядок»

Пошаговый мастер добавления стихов:
- **Шаг 1:** Указание автора и названия (с кнопкой авто-вставки).
- **Шаг 2:** Ввод или вставка текста стихотворения.
- **Шаг 3:** **Интеллектуальное приведение в порядок (автоочистка):**
  - Удаление мусора (хештеги `#стихи`, ссылки `https://...`, упоминания каналов).
  - Нормализация строф (устранение лишних пустых строк с сохранением структуры четверостиший).
  - Русская типографика (кавычки «ёлочки», длинные тире `—`, многоточия `…`).
  - Режим ручной доводки текста перед сохранением.

## 📚 Персональная библиотека

- Сохранение в `localStorage` браузера — стихи не пропадут при закрытии вкладки.
- Золотая классика из коробки (Пушкин, Лермонтов, Есенин, Тютчев, Блок, Ахматова).
- Быстрый поиск и фильтры: *«Все»*, *«⭐ Избранные»*, *«🎯 В процессе»*, *«🏆 Выучено»*.
- **Резервное копирование:** экспорт всей библиотеки в `.json` и импорт в 1 клик.

## 🚀 Быстрый запуск

### Запуск на компьютере:
Дважды кликните по файлу **`Запустить_приложение.bat`** — проект автоматически откроется в браузере по адресу `http://localhost:5173`.

Или через консоль:
```bash
npm install
npm run dev
```

## 🌐 Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub: **[https://github.com/new](https://github.com/new)** с именем `stikhi` (не добавляя README и .gitignore).
2. Запустите файл **`Отправить_на_GitHub.bat`** (или выполните `git push -u origin main`).
3. В настройках репозитория на GitHub: **Settings -> Pages -> Build and deployment -> Source** выберите **GitHub Actions**.
4. GitHub Actions автоматически соберет проект и развернет его на вашем бесплатном адресе:
   `https://psychomanya.github.io/stikhi/`
